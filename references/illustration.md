# 插画：风格锁定、生成、后处理

## 〇、色系必须跟随主色（硬规则，2026-11-05 用户明确要求）

**插画色块的色系必须与整图主色一致**：主色是蓝就全用蓝系（深/中/浅蓝层次），禁止出现绿色或其他跳色系。允许保留的只有参考图自带的中性装饰（如明黄小星芒，面积极小）。换主题换主色时，风格词里的色系列表必须同步替换，并先打样 1–2 张确认无旧色系残留。

## 一、两条路线的差别（务必先分清）

| 路线 | 做法 | 稳定性 |
| --- | --- | --- |
| 纯文字描述风格 | 提示词写"扁平手绘、粗描边、三色…" | 60–70%，常漂移 |
| **参考图驱动（推荐）** | 用户参考图作为 `image1` 传入 + 一句风格描述 | 90%+，实测 4 张零废稿 |

**有参考图一定用 image-to-image。** 参考图对风格的约束力远大于文字。

## 二、提示词模板

### A2. 贴纸图标风（粗圆马克笔线条，2026-11 定稿版）

```
参考这张图标的插画风格：粗圆的黑色马克笔线条勾勒轮廓，线条圆头、简洁可爱的贴纸风，
主体大面积留白或白色填充，仅用{主色系，如：深墨蓝、天蓝、浅蓝}做小面积扁平色块点缀
（占比不超过两成，不要用其他色系），主体旁边点缀少量明黄小星芒闪光装饰，
无渐变，无文字，纯白干净背景无任何杂色，完全正面平视的扁平二维视角。
主体：{内容表第四列}
```

### A. 浅色手绘线稿风（配米白/白底，multiply 融合）

```
参考这张知识卡片图中卡片的插画风格：深墨色细线稿勾勒，线条简洁有手绘感，
画面以线稿为主、大面积留白，仅用草绿、天蓝、明黄、橙红做小面积扁平色块点缀
（类似图中的高亮条、勾选框的用法），无渐变，无文字，纯白背景，正面平视扁平视角。
主体：{内容表第四列}
```

### B. 深色科技风（配深蓝底，screen 融合）

```
等距视角 3D 插画，磨砂玻璃质感，内部发光，主色深蓝到青蓝渐变，
左上方向单光源，柔和投影，无文字，纯黑背景，正方形构图。
主体：{主体描述}
```

### 两条必写、缺一必翻车

- `纯白干净背景无任何杂色`（浅色路线）——不写会出纸纹理灰底，回填露灰边
- `完全正面平视的扁平二维视角（不是等距视角、不是立体透视）`——不写会混进立体方块

深色路线反过来：`纯黑背景` + `等距视角`，且全图统一 30° 俯角与左上单光源，光影方向一乱立刻暴露拼凑感。

## 三、语义化：图要画出"他在做什么"

| 模块 | 别这样画 | 应该这样画 |
| --- | --- | --- |
| 隐私计算 | 一个锁 | 两个保险箱并排，中间一条数据流经过、各自上锁 |
| 区块链 | 一个方块 | 三个环环相扣的链环 + 一枚签发印章 |
| 数据流通 | 一个箭头 | 一根粗管道从 A 建筑穿过中间节点通向 B 建筑 |
| 联合风控 | 一个盾牌 | 三只手从三方向托起同一张风险热力图 |
| 资源采集 | 一堆圆点 | 三条小河汇入一座带大坝的水库 |

口诀：**谁（主体）通过什么（动作）得到了什么（结果）**。这句话写不出来，图一定画不对。

## 四、打样（强制，别跳）

1. 只做 4 张：主视觉、平台类、安全类、底座类；
2. 四张并排看：视角一致？描边粗细一致？配色一致？
3. 有一张不对就重抽，**不要凑合用**——风格一混，后面 20 张全废；
4. 通过后再批量，风格语句一字不改。

## 五、后处理（每批必做）

```bash
python3 scripts/normalize_illus.py assets/illus
```

做三件事：检测四角底色、把米灰底（~235）线性拉成纯白、输出逐张结果。提示词再严也常出 235 左右的灰底，不归一化会在 `multiply` 融合后显示为一块灰斑。

## 六、水印处理

生成图可能带右下角"AI 生成"水印。**图像编辑模型抹不掉**（实测无效）。可靠做法是用 PIL 定位后涂白或裁掉底部：

```python
from PIL import Image
img = Image.open('in.png').convert('RGB')
w, h = img.size
px = img.load()
for y in range(h - 120, h):          # 右上角区域涂白，按实际水印位置调整
    for x in range(w - 260, w):
        px[x, y] = (255, 255, 255)
img.save('out.png')
```

涂白后若出现比周围亮的白斑，说明底原本不是纯白——跑一次归一化即可，两者要配合使用。

## 七、素材库

- 命名：`语义-说明.png`，全英文前缀（`privacy-双保险箱.png`、`value-价值创造中心方块.png`）
- 目录：`assets/illus/`
- 后续新图**直接复用**库里同风格插画，新增才生成——这是"第二张比第一张快 10 倍"的原因

## 八、深浅底融合速查

| 画面底色 | 插画底色 | CSS | 说明 |
| --- | --- | --- | --- |
| 浅色 | 纯白 | `mix-blend-mode: multiply` | 白自动消失、深线保留，零抠图 |
| 深色 | 纯黑发光 | `mix-blend-mode: screen` | 黑自动消失、发光保留 |

`multiply` 在深色底上会变暗块、`screen` 在浅色底上会发灰——**选错方向，图一定脏。**
